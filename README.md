# Where Did I Put It?

A lightweight, ad-free home organizer web app built to track where important items (keys, documents, chargers, and household essentials) are stored.

## Features
- **Home Dashboard:** Quick stats, instant search, and pinned essentials.
- **Add & Edit Items:** Save item name, exact location, room tag, extra notes, and date.
- **Rooms & Filters:** Browse items by room or search across names, places, and notes.
- **Safe Delete:** Two-tap confirmation prevents accidental deletion.
- **Private & Offline-Ready:** Data stays in your browser's `localStorage`, with JSON Backup & Restore and Dark Mode.
